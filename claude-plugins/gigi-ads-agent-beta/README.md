# Gigi-Ads-Agent (Beta) for Claude Code

This GitHub-only package connects Claude Code to Gigi's Beta environment, which
is backed by the non-production pre-prod service. It is not submitted to
Anthropic's public marketplace.

The endpoint remains intentionally non-routable until the pre-prod AWS API
Gateway is provisioned. Use `/mcp` to complete pre-prod OAuth after the endpoint
is configured. Never put credentials in this package.
