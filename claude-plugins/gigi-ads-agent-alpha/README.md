# Gigi-Ads-Agent (Alpha) for Claude Code

This GitHub-only package connects Claude Code to Gigi's Alpha environment,
which is backed by the non-production staging service. It is not submitted to
Anthropic's public marketplace.

The endpoint remains intentionally non-routable until the staging AWS API
Gateway is approved and provisioned. Use `/mcp` to complete staging OAuth after
the endpoint is configured. Never put credentials in this package.
